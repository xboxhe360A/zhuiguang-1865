# 《追光1865》GDD 执行案 v1.0
> 2026-10-19 ｜ 依据：v5 大纲 + 玩法定版 v1.0（A骨架+C招牌）+ 美术定版 v3.1 ｜ 个人开发者·Godot 4.7·TapTap 章节制·竖屏

## 1. 一句话与支柱

**玩家扮演 1905 年档案整理员，翻开 1865–1895 三十年的现场档案，在真实历史事件里校出一座不存在的岛——然后亲手决定：把它编进哪一册。**

**三大支柱**（一切取舍的裁判）：
1. **手感是侦探**：每个谜题都有"手"的活（拖/转/叠/显/盖），不许出现"只是读一段字然后选 A/B"的题。
2. **证据不盖章**：游戏奖励"会怀疑"，不奖励"猜对官方答案"；存疑是合法且高频的正解。
3. **每张剧照可进入**：过场连环画之外，不存在只能看的画面。

## 2. 核心循环（分钟级）

```
档案桌(1905, 蓝晒) ──翻文件──▶ 卷首器物图版页 ──▶ 连环画过场(30s)
        ▲                                              │灰→艳爆发
        │                                              ▼
        └───── 卷间仪式(30s) ◀── 揭示 ── 现场点触探索+谜题(5–8min/场景)
                     │              (背景+立绘+前景三层)
                     ▼
              假说卡/异议卡入图鉴 ──▶ 下一档案
```
- **30 秒层**：翻文件、盖章、图鉴弹卡——即时反馈
- **5–8 分钟层**：一个现场场景的探索→谜题→揭示
- **40–60 分钟层**：一章（2 卷）= 3–5 个现场 + 2 次卷间仪式 + 1 场武戏
- **长线**：六章编册进度=三册书架实体化（存在四证/判无记录/记忆同源），每册厚度可见

## 3. 系统规格

### 3.1 校图（招牌）
- **对象**：透明图件（纸草带/stick chart/泥板拓片/奇普摹本/海军航迹…），每卷 2–4 张。
- **操作**：单指拖动、双指旋转缩放（阈值宽容：旋转 ±5° 内即算对齐）；叠放到现代海图透光台上。
- **反馈**：错位边=红色矛盾细线（伴随玻璃刮擦 SFX）；对齐=金色坐标点亮（和弦+光晕扩散）。
- **谜题语法**：①找齐（现场里寻回图件）②配对（哪两张属同一海岸）③排序（先叠谁）④修正（图上某点是错的，玩家圈改）⑤终审（章末把本章所有坐标叠上=大校图台）。
- **防呆**：每张图件有"把手"纹章（文明符号），点击提示=对应把手闪一下；连续 3 次错误对齐自动降一档吸附容差。

### 3.2 三声裁定（卷间仪式，30 秒）
1. 证据卡（≤15 字摘要+缩略图）拖入三册之一，**允许投"不编入"**（第四格=空白册，星野式留空合法）；
2. 盖评级章：真 / 伪 / **存疑**（三章全合法，存疑通过率高且保彩色留灰——与 E 机制联动）；
3. 批注轨对峙：伊莎贝拉编者按（褐墨小楷）与雷恩异议（红铅笔）各一句，**点异议卡翻面**→若玩家此前在现场拿过反驳物证，翻面露出下一档案入口（异议卡反用为线索）。
- **节奏**：仪式 BGM=单音大提琴+印章声，全程无失败态（裁定永不判玩家错）。

### 3.3 湿版显影
- 现场拍得的底片→暗房托盘：倾斜角度（陀螺仪或拖动）让显影液漫过；**漫过区域按 E 机制恢复彩色**。
- 谜题语法：读出隐藏影像（过度显影会烧掉细节=可逆失败）、负像判读（左右反字）、双底叠看。

### 3.4 半即时武戏（8 场，雾都含 1 场）
- 三幕：**节奏格挡**（剧照镜头推近，威胁线亮起时点对位置格挡，3–5 拍）→ **选招**（二器×三路线：杖剑/双拳 × 攻/守/拿，观礼者图标=左轮禁用提示）→ **结算演出**（一招定格剧照）。
- 全点触、无 QTE 死亡螺旋：连错 3 拍自动"让招"续接；可重打。
- 武德律：观礼者在场动左轮=当场失败+武德标记（剧情不坏，人物评价变）。

### 3.5 E 完整度调色盘（常驻）
- 场景饱和度=该档证据完整度：未裁定区灰斑脱乳剂；盖章瞬间彩色从印章处**涨开**（全游核心爽点，shader 实现）。
- 灰=可交互线索（"缺的部分能摸到"），彩=已确认——把机制语言藏进美术语言。

### 3.6 收集与图鉴
假说卡（每档最强假说+最弱环节，永不盖章）／报章辑（雷恩异议+时代八卦）／器物图版（卷首石印画收集）／评级履历（玩家全部裁定记录，终章听证会引用）。**无货币、无体力、无广告**——买断章节制。

## 5. UI 屏流与交互规范

```
启动(蓝晒压印) → 档案桌[主菜单/章节=卷宗/设置=油灯]
 → 卷首器物图版页 → 连环画过场 → 现场(背景+立绘+前景; 热区脉冲环; 底部黄铜舷窗道具栏; 左上纸折进度带)
 → 透光台(校图) / 暗房(显影) / 卷间仪式(三册+盖章) → 图鉴(书架) → 回档案桌
终章解锁：听证会大厅(全游最大校图台+三册呈递)
```
- **全点触**：点=交互，长按=细读（≤150 字档案浮窗），双击=放大；无打字输入（裁定全部拖卡+盖章）。
- 热区 ≥48dp；正文 ≥14pt；红矛盾线/金证据**双编码**（线型不同：红=锯齿、金=圆点）保色盲可玩。
- 存档：卷间仪式检查点+章内自动；TapTap 云存档（平台 SDK）。
- 无 HUD 文字按钮——菜单=纸签、音量=铜旋钮、退出=合上卷宗（diegetic 到底）。

## 6. 音频规格
- **档案层**：大提琴+走音钢琴+纸张/火漆拟音；**回溯层**：黄金期管弦，每章一主题，跨章变奏（卷八喀拉喀托=铜管嘶鸣）。
- **diegetic 优先**：界面音全部来自桌面实物（印章、抽屉、怀表咔哒）；武戏节奏点与鼓点绑定。
- 音乐自适应两层即可（探索/揭示），不做复杂垂直分层（个人开发者产能）。

## 7. 技术规格（Godot 4.7）
- 竖屏 1080×1920，锚点适配 18:9–20:9；目标中端机 30fps 稳。
- 场景=三层 CanvasItem（bg / character / fg）+ ShaderMaterial：E 调色盘（饱和度遮罩+盖章涨开=噪声阈值动画）、胶片颗粒+划痕（时间噪声叠加）、暗房红光（canvas modulate）。
- 透光台手势：拖拽+旋转用 Area2D+自定义 InputEvent 处理，吸附判定=极坐标容差。
- 数据驱动：谜题/档案/裁定全走 Resource（.tres），内容=数据不是代码——六章复用同一套系统。
- TapTap SDK 4.x：登录+防沉迷实名（平台通道）+云存档+内嵌动态。
- 资产管线：Agnes i2i 锁脸出图 → GIMP/rembg 抠图 → 三层合成 → 压缩（ASTC/KTX2）。

## 8. 产能与范围红线
- 单章生产包=背景 8–12 张 + 立绘 15–20 张 + 图件 UI 20 张 + 谜题脚本 11 题 ≈ 4–6 周（单人+Agent 流水线）。
- **红线**：不加语音配音（文本+拟音足够）；不做 3D；不做多周目分支（裁定履历已提供重玩性）；武戏不做实时格斗。
