## 四、生产纪律（摘自 GDD执行案 / UI文档，供后续美术对齐）

1. **每张剧照必须可进入可玩**：游戏画面 = 背景板 + 角色 sprite + 前景遮挡 三层 Godot 合成；单张概念插画仅用于营销。
2. **定妆只锁五官**：服装 / 道具 / 动作随场景按史实重设（i2i 锁脸 + 情境换装）。
3. **三层媒介**：档案层1905=压暗蓝晒；回溯层1865–95=40–50年代 Technicolor 剧照；过场=泛黄漫画页。
4. **翻开文件灰→艳**：饱和度即证据完整度，盖章回色为核心 juice 时刻。
5. **红线**：无配音 / 无 3D / 无分支 / 无即时战斗。
6. **字体只锁免费商用**（用户 2026-10-19 裁决）：思源宋体 SC（中文主）/ 思源黑体 SC（小字）/ IM Fell English（拉丁标题），均 SIL OFL 1.1；系统字体与"个人非商用免费"字体禁入。
