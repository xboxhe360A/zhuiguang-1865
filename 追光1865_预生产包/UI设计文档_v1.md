# 《追光1865》整体 UI 设计文档 v1.0
> 2026-10-19 ｜ 原则：**diegetic 到底**——屏幕上不允许出现不属于 1905 档案室的现代 UI 元素；一切按钮都是物件。竖屏 1080×1920。

## 0. 设计语言总则
- **两色两层**：1905 档案层=压暗蓝晒（靛蓝 #1e2a4a 底+灯芯暖金 #d9a441 点缀）；1865–95 回溯层=特艺彩色（青橙+酒红）。转场=翻开文件的灰→艳。
- **三texture**：纸（纤维/折痕/火漆）、黄铜（旋钮/框/链）、玻璃（透光台/底片/放大镜）。
- 字体：中文=仿宋正文+手书标题（档案签条），英文=维多利亚活字；正文 ≥14pt，热区 ≥48dp。
- 双编码：红矛盾线=锯齿细线，金证据线=圆点线（色盲可分辨）。

## 1. 屏流总图

## 2. 逐屏规格

### S1 档案桌（主菜单）
- 俯拍 45° 书桌：中央皮革台账《追光1865》=**开始/继续**；右侧五卷卷宗扇开=**章节选择**（已购章亮起，未购=火漆封）；左上煤油灯=**设置**（灯罩拧暗=音量）；台灯下压着报纸=**公告/更新**；黄铜 magnifier 拿起=**图鉴**。
- 进入章节动作：手（玩家视角）抽出卷宗翻开 → S2。全游戏没有"点击按钮"的感觉，只有"整理桌子"。

### S4 现场（核心游玩屏）
- 全屏剧照背景三层：bg（场景底）/ character（立绘，含呼吸微动+眨眼帧）/ fg（前景遮挡物件）。
- **热区**：悬停 0.5s 出现脉冲铜环；可拾物=环带挂钩图标。
- **道具栏**：底部黄铜舷窗框（最多 6 格），拾取=物件飞入并"咔哒"落位；组合=拖 A 到 B 上。
- **进度**：左上纸折 ribbon（本章已解谜题=折角数）。
- **菜单**：右上纸签"合上卷宗"=退出到 S1（自动存档检查点在 S8）。

### S5 透光台（招牌 UI）
- 全屏：发光玻璃台面（暗房环境里唯一光源，玩家的手和图件有投影）。
- 图件=半透明胶片，边缘有文明把手纹章；拖/转/缩放手势；吸附成功=金色坐标亮+和弦。
- 右侧牛皮纸卷轴=本档任务提示（拉一下展开一句，雷恩红笔批注=错误提示人格化）。
- 章末大校图台=同一 UI 放大到 1:1 桌面，全部图件同屏。

### S6 暗房
- 红光环境；显影盘=倾斜控制（拖动或手机倾角）；药液漫过处彩色恢复（E 机制）。
- 晾干绳=已显底片收藏位（横向滑动）。

### S7 武戏镜头
- 剧照推近+暗角收缩成 21:9 电影框（第一层"电影感"）；威胁线=亮起的弧线，点弧即格挡；
- 选招盘=三个怀表盘面（攻/守/拿 × 当前武器），武器切换=杖剑/双拳图标对调；
- 观礼者剪影在框边=左轮格（灰色+锁链纹）禁用提示。结算=一招定格成新的剧照（自动入图鉴"名场面"）。

### S8 卷间仪式（30 秒）
- 竖构图：三册书脊立像书架，证据卡从桌面滑到玩家手里（拖入册=归档动画+厚度+1）；第四格空白册="不编入"。
- 盖章：选章（真/伪/存疑）→ 手按下 → **彩色从印章处涨开**（E 机制高潮帧）+ 大提琴单音。
- 批注轨：左缘褐墨小楷（伊莎）与右缘红铅笔（雷恩）逐句浮现，对峙句加下划线交叉；点雷恩卡→翻面。

### S9 图鉴书架
- 实体书架五层：假说卡（夹在卷宗）/报章辑（剪贴簿）/器物图版（画册）/评级履历（账簿=玩家全部裁定记录）/名场面（相册=武戏定格+关键剧照）。
- 评级履历在终章被听证会引用——**图鉴不是赠品，是结局素材**。

### SH 听证会大厅（终章）
- 档案桌 UI 的"放大一万倍"：全游图件铺满长桌，三册呈递台，雷恩席位空着一把椅子（玩家把他的异议卡放进去——他死后/判无后第一次"入场"）。

## 5. 实现注记（Godot 4.7）
- 每屏=一个 PackedScene；S1/S8/S9 用 Control+TextureButton（物件即按钮）；S4/S5 用 Node2D 层+自定义命中区（CollisionShape2D 覆盖美术热区）。
- E 调色盘=单 shader（`_SatMask: Texture2D` + 盖章点 uniform 动画阈值）；胶片颗粒=全屏 canvas_item 噪声叠加。
- 全部文案走 CSV 本地化表（简中首发，繁中/英预留）。
